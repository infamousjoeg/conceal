        Who keeps the agent from approving itself?
        
The operator must run Conceal in a trusted environment that the untrusted agent cannot control. The real candidate does not include an agent connector or sandbox. An agent with unrestricted access to your account could run approve or read your keys itself.

        
Use the deployment guide before connecting an agent. This page teaches the decision flow; its buttons do not establish that security boundary.
